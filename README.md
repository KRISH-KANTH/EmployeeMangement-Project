# Employee Management Project

A simple Java console application for managing employee records. Users can add, view, update, and delete employee details through a menu-driven interface.

## Features

- Add employee records
- View all employees
- Update employee details
- Delete employee records
- Automatically assign each employee a unique ID
- Store employee data while the application is running

> This version stores data in memory. Records are cleared when the application closes.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections Framework

## Employee Details

Each record includes:

- Employee ID
- Name
- Department
- Salary
